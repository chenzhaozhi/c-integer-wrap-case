# c-integer-wrap-case

C 移植有/无符号整型回绕评审练习场。

## 案例背景（来自公开技术博客截图，用户提供）

锁相环/频率合成驱动移植：由 demo 原版改写成嵌入式目标代码后，计算结果悄悄出错。

场景：Fvco = VCO 频率，xtal = 晶振频率，参考频率 ref = xtal*7，目标量 chan_frac 为通道小数分频值。

- 原文称：demo 的 `(Fvco % ref) - ref` 恒为负（实测 -40000），移植时把中间变量声明成 UINT32 导致回绕成 4294927296，随后 `<<12` 高位丢弃。
- 原文结论：`UINT32 chan_frac_v` 是"元凶"。
